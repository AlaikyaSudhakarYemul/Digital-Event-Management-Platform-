Logout Button

Frontend UI component: UserDashboard.js
Frontend API calls triggered from: None — frontend only
What it does:

Removes all auth keys from localStorage (user, auth_token, authToken, token, adminToken etc.)
Clears sessionStorage
Clears cookies
Calls window.location.replace('/') → goes to home page
Backend: Not involved — no backend logout endpoint
