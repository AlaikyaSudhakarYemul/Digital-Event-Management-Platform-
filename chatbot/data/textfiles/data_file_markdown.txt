# How to Create an Event - Project Guide

## Event Creation Workflow

### Prerequisites
- Sign up or log in as **Organizer**
- Only organizers should create events

### Step-by-Step Process

#### 1. Open Create Event Page
Go to the event creation form from the organizer dashboard.

#### 2. Fill Basic Details
Enter the following information:
- Event Name
- Description
- Date
- Time

#### 3. Choose Event Type
Pick one of the following:
- `IN_PERSON`
- `VIRTUAL`
- `HYBRID`

#### 4. Fill Location Rules
- **IF IN_PERSON or HYBRID**: Select an address/location
- **IF VIRTUAL**: No address needed

#### 5. Select Speaker
Choose at least one speaker from the available list.

#### 6. Set Max Attendees
Enter a number between **10 and 500**.

#### 7. Add Event Image (Optional)
You can upload an image, but it is not mandatory.

#### 8. Submit
Click **Create Event** button.

#### 9. Success Message
You should see a success popup, and the event gets created.

## FAQ - Event Creation

### How do I create an event?
Login as organizer, open Create Event form, fill details, then click Create Event.

### Where is the create event page?
In organizer side, go to dashboard and open **Create Event**.

### What details are required to create an event?
- Event name
- Description
- Date
- Time
- Event type
- Max attendees
- Speaker
- User ID
- **Note**: Address is required for in-person and hybrid events.

### Can I create a virtual event without address?
**Yes.** For `VIRTUAL` event type, address can be empty.

### What is the valid max attendees limit?
In your frontend validation, allowed range is **10 to 500**.

### What event types are allowed in this project?
- `IN_PERSON`
- `VIRTUAL`
- `HYBRID`

# Password Reset Guide

## How Do I Reset My Password?

### Step 1 — Open Login Page
Go to the DEMP app and click **Login**.

### Step 2 — Click "Forgot Password?"
Below the login form, click the **Forgot Password?** link.

### Step 3 — Enter Your Email
Type the email you registered with and submit.

### Step 4 — Check Your Inbox
You will receive a password reset link by email.
- **Not found?** Check spam/junk folder.

### Step 5 — Click Reset Link
The link contains a secure token. It expires after some time, so use it quickly.

### Step 6 — Set New Password
Enter a strong new password (must meet length and complexity rules).

### Step 7 — Login With New Password
Go back to login page and login normally.

# Ticket Booking Guide

## How to Book a Ticket (User)

1. **Select an event**
2. **Choose ticket type** (General, VIP, Early Bird, Group, etc.)
3. **Enter quantity and attendee info**
4. **Complete payment**
5. **Get e-ticket** via email and in My Tickets section
6. **Show QR code** at event entry

- Uppercase + lowercase
- Number + special character

### Step 12: If rules pass, system updates password

### Step 13: Chatbot confirms
> "Password reset successful. Please login now."
