Intent: create_event
Question: How do I create a new event?
Answer: Log in as organizer, open Create Event form, fill required details, and submit.
Steps:
1. Log in with organizer account.
2. Open Organizer Dashboard and click Create Event.
3. Enter event name, description, date, time, and event type.
4. Add speaker and max attendees.
5. Add address for IN_PERSON or HYBRID events.
6. Click Create Event and confirm success.
Keywords: create event, organizer, event form

--------------------------------------------------
Intent: create_event_required_fields
Question: What details are required to create an event?
Answer: You need name, description, date, time, event type, max attendees, and speaker.
Steps:
1. Enter event name and description.
2. Select date and time.
3. Choose event type.
4. Add speaker.
5. Set max attendees between 10 and 500.
Keywords: required fields, event details, validation

--------------------------------------------------
Intent: virtual_event_no_address
Question: Can I create a virtual event without address?
Answer: Yes. Address is not required for VIRTUAL events.
Steps:
1. Open Create Event.
2. Set event type to VIRTUAL.
3. Leave address empty.
4. Submit event.
Keywords: virtual event, address optional

3. Submit after validation passes.
