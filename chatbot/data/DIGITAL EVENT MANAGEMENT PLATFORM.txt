Login to Admin Account:
 
email and password 

Important point: there is no separate backend “admin login” API. Admin and normal user both use the same backend login endpoint in UserController.java. The frontend admin page in AdminLogin.js is what decides that only users with role ADMIN can continue to the admin dashboard.

If you want, I can draw the exact flow as:

enter email/password
frontend POST
backend validate
JWT return
admin dashboard open

Frontend side:

The admin login screen UI is in AdminLogin.js.
The form fields email and password are controlled with React useState.
When you click Login, the function handleLogin() sends a request to http://localhost:8080/api/auth/login.
After the response comes back, this frontend code checks data.user.role !== 'ADMIN'. If the role is not admin, it blocks access on the frontend.
If the role is ADMIN, it saves the token with setAdminToken() from authService.js, stores user info in localStorage, and navigates to /admin/dashboard.

So, in simple words, the admin page itself is “built” here:

UI and submit logic: AdminLogin.js
Token storage helper: authService.js

Backend side:

The login API is implemented in UserController.java.
The method is login(@RequestBody Map<String, String> loginData).
It reads the email and password from the request body.
It calls userService.findByEmail(email) to load the user from the database.
It checks the password using passwordEncoder.matches(password, user.getPassword()).
If valid, it creates a JWT token using jwtUtil.generateToken(user.getEmail(), user.getRole()).
Then it returns both the user object and token to the frontend.
